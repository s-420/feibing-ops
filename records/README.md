# 业务处理留痕

> 每次真实业务处理，留一条记录。价值：可回溯、可交接、可复盘。

## 组织方式

- 按「时间」分目录：`records/YYYY-MM-DD/`。
- 文件名：`<客户>-<对象>-<动作>.md`。

## 记录字段（固定 7 个）

`时间 / 客户 / 对象 / 动作 / 处理人 / 结果 / 待办遗漏`。

## 模板

见 `templates/留痕记录.md`。

## 与台账的关系

- 本 `records/` 是「业务留痕」（小组共享，进仓库）。
- 个人每日任务另有本机台账（不进本仓库）。
- agent 处理业务时，两边都记：台账记「今天干了啥」，`records/` 记「这个客户问题怎么解决的」。
