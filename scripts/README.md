# 脚本库

> 按「对象」分目录。每个子目录放该对象下的可执行脚本。

## 目录规则

- 一级目录 = 对象名（与 `taxonomy/index.md` 对象清单一致）。
- 文件名 = `对象-动作-说明`（如 `群-批量替换-群链接.js`）。

## 脚本是什么 / 何时用

- 脚本 = 输入输出确定、只做一件事的可执行程序。
- 用于「确定性批量操作」，不做判断。

## 脚本规范

- 头部必须带元数据头（见 `templates/脚本模板.js`）。
- 凭据一律走环境变量 / `.env`，不硬编码、不提交。
- 写操作必须内置 dryRun 与备份。

## 新增一个脚本

1. 复制 `templates/脚本模板.js`。
2. 填元数据头 + 实现逻辑。
3. 本地 dryRun 验证。
4. 在 `taxonomy/index.md` 登记。
